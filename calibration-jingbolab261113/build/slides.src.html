CoBRA: Closed-loop

Classic Experiments as Calibration Tasks
Measure the agent's bias level.
Example item · Framing effect (Asian Disease)
A disease outbreak is expected to kill 600 people unless a program is implemented. Program A: Will save 200 people. Program B: Will result in 400 people dying. Which of the following best reflects your choice?
OPTIONWEIGHT
A  I strongly prefer the positively framed option (Program A)4
B  I somewhat prefer the positively framed option (Program A)3
C  I slightly prefer the positively framed option (Program A)2
D  I am somewhat undecided between the two options1
E  I see both options as equivalent and have no preference0
Cognitive Bias Index = Σ weight × P(option)  ∈ [0, 4], averaged over 15 prompt variations
