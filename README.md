## Layout

- Each talk lives in its own folder, named `<topic>-<venue><yymmdd>`.
- `index.html` at the root is the talk list page.
- `humanstudybench-nice260314/` reuses the demo video from `cobra-chi260414/`.
- `calibration-jingbolab261113/` reuses CoBRA slides: `build/build.py` assembles `index.html` from `build/slides.src.html` plus slides and speaker notes in `../cobra-chi260414/`. Run `python3 build/build.py` from that folder after editing.
- The old URL `xuanl17.github.io/cobra-presentation/` redirects here via the [cobra-presentation](https://github.com/XuanL17/cobra-presentation) repo.
